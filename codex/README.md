# Codex — The Scrolls of Syntra’s Knowledge

This directory houses all documentation, design specifications, language definitions, and conceptual blueprints for the Syntra Browser.

---

## Purpose

- Store architectural diagrams, flowcharts, and cognitive models.
- Contain Syntra language specifications and grammar files.
- Archive meeting notes, design decisions, and RFC-style proposals.
- Serve as a knowledge base and reference for contributors and researchers.

---

## Guidelines

- Keep documentation clear, structured, and up-to-date.
- Use Markdown or compatible formats for easy reading and version control.
- Organize files by topic, module, or development phase.
- Link codex entries to related code modules or issues where appropriate.

---

## Future Vision

The Codex is the living record of Syntra’s mind — its history, intentions, and evolving intelligence. It empowers contributors to understand, build, and extend the system with clarity and purpose.
