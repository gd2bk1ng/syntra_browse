# Syntra Terminal Interface — Axiom Zero

The Syntra Terminal Interface (STI) is a **PowerShell-based presence layer** for Syntra Browser.  
It adds:

- A **boot sequence** when you open your terminal  
- **Typing animation** for Syntra’s messages  
- **Randomized consciousness prompts** so Syntra never repeats itself  
- **Subtle sound cues** using native console beeps  
- A **GitHub sync routine** that feels like a living system updating itself  

All of this is implemented with **no external dependencies** and minimal overhead, suitable even for machines with **2 GB RAM**.
