# Syntra Terminal Themes

This directory is reserved for future **Syntra Terminal themes**, such as:

- **Prime** — formal AGI steward  
- **Ghost** — whispering oracle  
- **Butler** — elegant assistant  
- **Core** — developer diagnostics mode  
- **Neon** — cyberpunk visual style  

Each theme will define:

- Color palette  
- Message style  
- Boot sequence flavor  

For now, the default theme is defined in `terminal/syntra.ps1`.
